How it works

  1. Sign in

    Index number, then a quick face scan.

  2. Pick your course

    Tap Mark attendance when the class is open.

  3. Check in

    Index number, face scan, then scan the QR code or type the code on the board. You must be within range of the admin.

  4. Confirm at the end

    In the last minutes of class, tap Confirm while you're still there. Leave early and you're marked absent.

Your face is locked to your index number when you register. Only the admin can reset it.
